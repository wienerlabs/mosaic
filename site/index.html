A multi-proving-system verifier library for Solana. One trait, one dispatch surface, four proving systems.

01What it is

Mosaic is a Rust workspace that implements on-chain verifiers for Groth16, KZG-PLONK, HyperPlonk-KZG, Halo2-KZG, Nova / HyperNova / ProtoStar folding schemes, and FRI-STARK — all behind a single ProofSystem trait and a single VerifyProof instruction dispatcher.

Consumers pick a verifier by discriminant; the same canonical byte-format and error taxonomy flows through every system.

04Soundness gates

Each verifier surfaces tampered prover data with specific error codes before the final structural check. A gate is a cryptographic pre-filter — an audit firm traces soundness through these per-system.

Verifier Gate
HyperPlonk-KZG Sumcheck identity, permutation term at ξ (2 gates)
Halo2-KZG Vanishing identity, two-point batched KZG opening at (ξ, ξω)
Nova / HyperNova / ProtoStar Hadamard residual, folded-commitment reconstruction (2 gates)
FRI-STARK Query indices, trace + constraint Merkle, PoW, FRI fold chain, OOD quotient, per-layer Merkle auth (7 gates)

05Architecture

 mosaic-program
       │
       │ dispatch_verify(ProofSystemId, vk, proof, pi)
       │
       ├── Groth16        ──┐
       ├── KZG-PLONK      ──┤
       ├── HyperPlonk     ──┼── mosaic-zk-primitives
       ├── Halo2-KZG      ──┤   (fr, field, msm,
       ├── Nova           ──┘    transcript, g1_consts)
       └── FRI-STARK   ────── mosaic-stark
                              (Goldilocks, Merkle, FRI fold)

The BN254 primitives live in mosaic-zk-primitives and are shared across four verifier crates. STARK-specific Goldilocks + Merkle + FRI primitives stay local to mosaic-stark.
